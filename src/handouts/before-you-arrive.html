02

Install

~10 min
  • Bob IDE — bob.ibm.com/download, open it and sign in with your IBMid macOS: mac-ARM (M1 or newer) or mac-Intel · Windows: x64 (User)
  • watsonx Orchestrate ADK extension, in Bob IDE: Extensions view (Cmd/Ctrl+Shift+X) → search “watsonx Orchestrate” → Install Install only; don't open it or set up a workspace with it.
  • Python 3.11, 3.12 or 3.13 — check: python3 --version Mac brew install python@3.11 · Win winget install Python.Python.3.11
    Windows installer: tick “Add Python to PATH”.
  • uv — check: uv --version Mac brew install uv · Win winget install astral-sh.uv
    Then open a new terminal and check again.

Don't create a Confluent Cloud account yet

We do it together in the lab, so the promo code goes in at the right moment and you're never asked for a credit card. Already have one? Just bring the login.

Bring

  • A laptop you can install software on (try at home: work laptops may block it)
  • Your charger, and access to your email for verification codes
  • If you did step 03: your watsonx Orchestrate URL and API key

  • python3 --version shows 3.11–3.13
  • The ADK extension is installed in Bob IDE
